T1. Implement and validate dual-pivot Quicksort

Algorithm Implementation & Strategy:

An in-place Dual-Pivot Quicksort (Yaroslavskiy-style partition) implemented in Rust without external sorting dependencies. For a given slice range $[0, n-1]$, the algorithm deterministically designates the first element as $p$ and the last element as $q$. If $p > q$, they are swapped immediately so that the precondition $p \le q$ strictly holds.

Partition Invariants:

During the partition loop, the active pointer $k$ traverses from $lt$ up to $gt$, maintaining the elements partitioned across four distinct regions:

$$\forall i \in [1, lt - 1]: arr[i] < p \quad \text{(Region 1: strictly smaller than left pivot)}$$ $$\forall i \in [lt, k - 1]: p \le arr[i] \le q \quad \text{(Region 2: between pivots)}$$ $$\forall i \in [k, gt]: \text{uninspected elements (Region under active scanning)}$$ $$\forall i \in [gt + 1, n - 2]: arr[i] > q \quad \text{(Region 3: strictly greater than right pivot)}$$

Upon loop termination ($k > gt$), the pivots are swapped into their final positions: $p$ is placed at $lt - 1$ (index $p_1$), and $q$ is placed at $gt + 1$ (index $p_2$).

Recursive Ranges & Duplicate Handling:

  • Left subarray: $[0, p_1 - 1]$ contains elements $< p$ → recursively sorted.
  • Right subarray: $[p_2 + 1, n - 1]$ contains elements $> q$ → recursively sorted.
  • Middle subarray: $[p_1 + 1, p_2 - 1]$ contains elements $x \in [p, q]$.
    • Case $p < q$: recursively sorted.
    • Case $p == q$: since $p \le x \le q$, every element in this region is guaranteed to be equal to $p$ (and $q$). Recursing on this range is skipped entirely. This eliminates $O(n^2)$ recursion degradation on duplicate-heavy and all-equal inputs.

The answers:

  • Partition Invariants: Pointer $k$ acts as the linear inspector, placing smaller values behind $lt$ (via left swap) and larger values behind $gt$ (via right swap). Uninspected elements shrink monotonically inside $[k, gt]$ until convergence.
  • Recursive Slicing: Subranges are safely split via split_at_mut to satisfy the Rust borrow checker without overlapping mutable references or unsafe pointer arithmetic. Pivots $p_1$ and $p_2$ are explicitly isolated from all sub-calls.
  • Termination on Duplicate/All-Equal Data: When $p == q$, all elements in the middle region are identical to the pivots. Bypassing the recursive call on the middle segment prevents infinite or quadratic recursion chains, guaranteeing termination on homogeneous datasets.
